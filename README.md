# Beetle's Burrow
A game where you play as a beetle and you have to save the lost beetles under a tree. Created for Sepetember's Jame Gam.

# Plot + How to play
You need to find all 6 beetles that were hidden around the giant tree. Some may refuse to go unless you bring certain objects, like plushies or food.

You can use WASD + Space to move and jump. Pressing E lets you interact with objects.
To collect the beetles, walk into them and it should collect (Some require you to do the prompt above them though)
Play the game here!: https://itch.io/jam/cozy-fall-jam-2026/rate/5064011
